# examples

The `robometrics` tool works without anything in this directory. These files are
a reference display built on top of the public JSON report format — open
[`viz.html`](viz.html) in a browser and drop a `report.json` (from `robometrics
analyze --json report.json ...`) onto it; it reads only what
[`FORMAT.md`](FORMAT.md) documents, nothing from the C++ internals. Write your
own if you want a different view.
